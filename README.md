## 🎯 Objetivo Principal

Este repositorio nace con un propósito claro: **estudiar, practicar y dominar** los problemas de LeetCode utilizando **Python**. Aquí documento mis soluciones, optimizaciones y notas personales para mejorar mi lógica de programación y estar preparado para entrevistas técnicas.

> *"La constancia es la clave para dominar las estructuras de datos y algoritmos."*

---

## 🧠 ¿Por qué Python?

Elegí Python para este desafío por varias razones:
- **Sintaxis limpia y expresiva:** Permite enfocarme en la lógica del algoritmo en lugar de escribir código repetitivo (boilerplate).
- **Librería estándar robusta:** Herramientas como `collections`, `heapq` y `itertools` son increíblemente útiles para resolver problemas complejos de manera eficiente.
- **Popularidad en la industria:** Es uno de los lenguajes más solicitados en entrevistas técnicas de las empresas Top Tech (FAANG).

## 💡 Cómo navegar por las soluciones

Dentro de cada archivo (como `1-twosum.py`) podrás encontrar:
